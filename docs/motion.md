# Motion

Lagom must feel fast and modern. Motion confirms an action. It never delays one.

Reference: the original Spark (2015–2016). Simple, quick and satisfying.

## Rules

1. The action happens at once. The animation plays on top. The user can press the next key before it ends.
2. Short. 120–200 ms for most motion. Never more than 300 ms.
3. Two easings. Ease-out (fast out, gentle stop) for fades, colour and the compose sheet leaving after Send. A spring (`motion::spring`, about 3 % overshoot, settled within the same duration) where an object moves in space and lands: a row springing back or coming back on Undo, a row leaving, the palette and compose arriving, toasts. Never a spring on opacity or on the selection highlight; a bounce there reads as jitter when J is held.
4. Motion carries meaning. Every animation shows where something went.
5. Gestures follow the fingers 1:1 and lock to one direction after a few pixels. Release past the threshold acts; short of it, the object springs back. Momentum never acts.
6. Respect the system "reduce motion" setting. Fall back to a short fade.
7. 60 fps minimum on all three platforms. Drop an animation before dropping frames.
8. Everything clickable answers the pointer: a hover tint (`hover`, between the surface and `sel`) and a press tint (`press`, past `sel`), both instant like native macOS controls. Filled buttons fade to 92 % on hover and 80 % on press instead. A selected row keeps `sel` under the pointer.

## Key moments

| Action               | Motion                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Done (E)             | The row slides out to the side with an accent tint, and the list closes the gap. The next message is selected at once.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Delete (⌫)           | Like Done, but to the left over the danger colour. A "Deleted" toast offers Undo (⌘Z) for 5 s.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Swipe (trackpad, mouse) | The row follows two fingers 1:1, or the pointer when a row is dragged with the mouse (a press that moves under 6 px stays a click; a mostly vertical drag does nothing). Right has one stage: Done past 120 px. Left has two: Later past 120 px, Delete past about 60 % of the row (245 px). The background behind the row shows the move a release would make: neutral (`sel`, ink2 icon) short of 120 px, then `swipe_done` (pine green), `swipe_later` (gold) or `danger`, with the icon in `accent_ink`. Crossing a stage cross-fades the colour in 100 ms and swaps the icon (later ↔ trash); the row never waits for it. Let go past a stage and the row leaves as with E, L or ⌫. Short of it, or on Esc, it springs back in 180 ms on the spring. A mouse release outside the window counts as letting go. |
| Exit colours         | E, L, ⌫ and ⌘K "Move to" show the same colours behind the leaving row as the swipe, so keys and swipes look alike. The colour fades out with the row.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Later (L)            | The row lifts and shrinks towards "Later" in the sidebar. The count there ticks up.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Compose              | Rises 12 px into place on the spring and fades in, 200 ms. Undo after Send plays the same arrival.
| Send                 | The compose window slides up and out (ease-out). A short "Sent" toast confirms it, with Undo.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Undo                 | The reverse of the original motion.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Inbox reaches zero   | A small, calm moment: the "Nothing left." state fades in with one illustration. No confetti.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Selection (J, K, click) | The highlight glides to the new row in 140 ms ease-out, from wherever it is, so a held J never jumps. The list scrolls the row into view. While rows leave or come back, the rows paint the selection themselves.
| Command palette (⌘K) | Fades in and drops 8 px into place on the spring in 120 ms. GPUI has no scale transform, so the 0.98 → 1 scale is out. The pointer moves the selection like the arrow keys; a click runs the item.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Counts               | Numbers roll, they do not jump.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

## Implementation

GPUI has animation built in (`with_animation`, `Animation`, easing functions). Use it before adding a dependency.
