# Lagom — brand and UI design prompt

Paste everything below the line into Claude design.

---

Design the brand identity and first UI concept for **Lagom**, a desktop email client.

## Product

- A fast, minimal, keyboard-first email client. Rust core. macOS, Windows and Linux first. Mobile later.
- One job: get the user back to an empty inbox with the least effort.
- No AI features, no team features, no clutter.
- Open source. The landing page shows the source link and the licence plainly. No pricing page, no sign-up wall.
- References for discipline: the original Spark (2015), Linear, Raycast.

## The name

Present the name as a dictionary entry. This entry is the core brand asset:

> **lagom** /ˈlɑːɡɔm/ ("LAH-gom") _adv., adj._ Swedish.
> Not too much. Not too little. Just right.

Use the entry on the landing page hero, the about window and the empty-inbox state.

## Feeling

- Made in Sweden. Retro Scandinavian catalogue design from the 1960s and 1970s.
- Honest, plain and friendly. Flat-pack clarity: every part has a purpose and a label.
- Stripped down. If an element does not help the user reach zero, remove it.
- Dry Swedish humour in small doses. Never cute.
- A light IKEA-catalogue feel is welcome: product-tag labels, numbered assembly steps and plain shopping-list rows (think of a favourites list).

## Visual direction

- **Type:** one sturdy geometric or grotesque sans for everything. Heavy weight for the wordmark, set in lowercase. A monospace face for shortcuts and counts.
- **Colour:** warm off-white paper, near-black ink and one strong accent. Explore a Swedish palette: falu red, mustard yellow, pine green and catalogue blue. Pick one accent per concept. Provide light and dark themes.
- **Shape:** flat colour, hard edges, small radii. No gradients, no glass, no shadows beyond one hairline.
- **Illustration:** assembly-manual line drawings. One line weight, no fill. Use them for empty states and onboarding.
- **Icon:** a simple flat mark that works at 16 px. Explore the letter "l", a level or balance line, and an empty tray.
- **Copy:** short and literal. Example for an empty inbox: "Lagom. Nothing left."

## Hard limits

- Do not copy IKEA. No blue-and-yellow wordmark block, no IKEA typefaces, no IKEA product-name parody, no assembly figure lookalike. The reference is the era and the attitude, not the company.
- No stock Scandinavian clichés: no Dala horses, no Vikings, no flags.

## Deliverables

1. Three distinct brand concepts on one canvas. Each has a wordmark, an app icon at 1024, 128 and 16 px, a palette and a type sample.
2. For the strongest concept: the main window (account list, message list, reading pane), the command palette, the empty-inbox state and a compose window.
3. A landing page hero for the product site with the dictionary entry.
4. A one-page brand sheet: colours with hex values, type scale, spacing unit, icon rules and three copy examples.

State which concept you recommend and why, in three sentences or fewer.
