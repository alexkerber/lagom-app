## Agents without a mark

- Claude Code and Claude Desktop: Anthropic's trademark guidelines
  (https://www.anthropic.com/legal/trademark-guidelines) allow its marks only as Anthropic
  permits and in materials it approves beforehand. lagom has no such approval, so both show a
  monogram tile.
- Hermes: its repository (NousResearch/hermes-agent) ships a different character than the
  agent's avatar, so it shows a monogram tile.
- Remote agents and test agents show a monogram tile.

Do not draw or redraw marks by hand.
